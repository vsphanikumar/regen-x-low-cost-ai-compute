# Architecture

The repository follows a lightweight architecture designed for local demo use:

- React + TypeScript frontend for the dashboard and analytics views
- Express API for telemetry, jobs, and orchestration logic
- optional Google GenAI integration for AI-assisted routing decisions
- in-memory state for simulation and ledger data
- compliance and verification views for product walkthroughs

This is intentionally a small, understandable application architecture that makes the concept accessible for review and demonstration.
