# AI agents

The orchestration flow is designed to simulate a compact operating model with specialized decision layers:

- telemetry ingestion and monitoring
- infrastructure governor and routing logic
- workload constraint enforcement
- compliance and verification views

The repo contains both an Express-based implementation and a Python FastAPI prototype in `backend/app/main.py` for comparison and experimentation. The goal is to model the decision loop clearly without overselling the implementation as a production energy-control system.
