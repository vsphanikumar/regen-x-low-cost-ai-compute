# Contributing

Thank you for your interest in REGEN-X.

## Working approach

1. Create a focused feature branch for your change.
2. Keep the work scoped and easy to understand.
3. Make sure the code and documentation remain aligned.
4. Validate the relevant project checks before submission.

## Code expectations

- prefer clear TypeScript and maintainable UI structure;
- keep the demo honest and avoid claiming real production capabilities when the code is simulation-based;
- document any new route, configuration, or workflow behavior in the appropriate docs file.
